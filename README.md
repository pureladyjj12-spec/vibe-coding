# Vibe Coding (바이브 코딩) 소개 웹페이지

AI와 함께 감각과 직관으로 소프트웨어를 만드는 새로운 개발 패러다임, **바이브 코딩(Vibe Coding)**을 소개하는 모던 랜딩 페이지입니다.

## ✨ 주요 특징
- **감성적 히어로 섹션**: 에디토리얼 무드의 시네마틱 비주얼과 인터랙티브 3D 틸트 효과
- **바이브 코딩 정의 및 3대 핵심 특징**: 직관적 자연어 중심 개발, 압도적 민첩성, 창의성 집중
- **기존 코딩 vs 바이브 코딩 비교**: 두 패러다임의 차이점을 한눈에 보여주는 대비형 그리드
- **반응형 햄버거 메뉴**: 모바일 및 태블릿(768px 이하) 해상도에서 우측 슬라이드 드로어로 부드럽게 전환
- **다크 글래스모피즘 & 오로라 배경**: 마우스 반응형 오로라 시차 및 블러 비주얼

## 🛠 기술 스택
- HTML5 (시맨틱 마크업)
- Vanilla CSS3 (CSS 변수, 글래스모피즘, 반응형 미디어 쿼리, 부드러운 애니메이션)
- Vanilla JavaScript (스크롤 스파이, 3D 틸트, 모바일 드로어 인터랙션)
